# Information-Thermodynamic Technosignatures: A Feasibility Framework

Detection of engineered/technological activity is feasible only where physics forces the information budget into view: entropy export (waste heat), deliberately structured low-entropy emission (design features), and long-lived scars in composition and dynamics. The content of efficient engineering is unobservable — a capacity-optimal signal is spectrally indistinguishable from thermal noise.

Channels ranked by expected yield:

1. **Entropy budget (waste heat)** — recommended primary channel; the second law guarantees it and archival data (Gaia DR4 + WISE/SPHEREx) can already test it via the entropy-excess observable Ξ.
2. **Design features** — GF(2) rank deficits (linear error-correcting codes), finite signal constellations, high-κ exact periodicity. The only channel that can support an "artificial" claim.
3. **Cradle archaeology** — composition/structure/dynamics scars persisting for Gyr; secondary scoring only.
4. **Gravitational/compact objects** — lowest yield; fabrication routes are closed by known physics.

Claim tiers: **Anomaly** (natural model family rejected at ≥5σ global significance), **Candidate** (admissibility violation, independently re-detected), **Artificial** (design-feature test replicated on at least two independent facilities).
